═══════════════════════════════════════════════════════════════════════
  方法一：AppImage 免安装版（推荐试用 / 快速体验）
═══════════════════════════════════════════════════════════════════════

  步骤一：复制文件
  ─────────────────────────────────────────────────────────────────
  将「食堂智慧管理系统-0.0.0-arm64.AppImage」文件复制到电脑任意文件夹

  步骤二：赋予执行权限
  ─────────────────────────────────────────────────────────────────
  右键点击该文件 → 选择「属性」→ 切换到「权限」标签页
  → 勾选「允许作为程序执行文件」

  步骤三：运行程序
  ─────────────────────────────────────────────────────────────────
  双击文件即可启动，首次启动约需 5-10 秒

  【备用方案：命令行启动】
  如果双击无法打开，请打开终端执行以下命令：

      chmod +x 食堂智慧管理系统-0.0.0-arm64.AppImage
      ./食堂智慧管理系统-0.0.0-arm64.AppImage

  【卸载方式】
  直接删除 AppImage 文件即可，不会在系统中留下任何残留


═══════════════════════════════════════════════════════════════════════
  方法二：deb 安装包版（推荐正式部署 / 长期使用）
═══════════════════════════════════════════════════════════════════════

  步骤一：安装 deb 包
  ─────────────────────────────────────────────────────────────────
  将「react_0.0.0_arm64.deb」复制到电脑后，双击安装

  【备用方案：命令行安装】
  打开终端，执行以下命令：

      sudo dpkg -i react_0.0.0_arm64.deb

  步骤二：修复依赖（如需要）
  ─────────────────────────────────────────────────────────────────
  如果安装时提示依赖缺失，执行：

      sudo apt-get install -f

  步骤三：启动程序
  ─────────────────────────────────────────────────────────────────
  安装完成后，在开始菜单搜索「食堂智慧管理系统」即可打开

  【卸载方式】
  打开终端执行：

      sudo dpkg -r react

  网络环境说明
═══════════════════════════════════════════════════════════════════════

  ✅ 完全离线可用
  ─────────────────────────────────────────────────────────────────
  本系统采用本地 SQLite 数据库，所有数据存储在电脑本地，
  无需连接互联网，纯局域网环境即可正常使用全部功能。

  ⚠ 关于图片显示
  ─────────────────────────────────────────────────────────────────
  演示数据中的部分菜品照片和监控截图来源于网络图片，
  在无外网环境下可能无法加载显示。此情况：
    • 不影响任何功能操作
    • 不影响数据录入、查询、统计
    • 用户自行上传的本地图片/截图均可正常显示


═══════════════════════════════════════════════════════════════════════
  多电脑数据同步
═══════════════════════════════════════════════════════════════════════

  说明：每台电脑的数据各自独立保存，默认不自动同步。

  如需多终端共享数据，请使用「备份/恢复」功能：

  步骤一：备份数据（电脑A）
  ─────────────────────────────────────────────────────────────────
    1. 打开应用，进入「系统管理 → 数据库管理」
    2. 点击「备份数据库」
    3. 系统将导出 .db 文件，保存到指定位置

  步骤二：恢复数据（电脑B）
  ─────────────────────────────────────────────────────────────────
    1. 在电脑B打开应用，进入「系统管理 → 数据库管理」
    2. 点击「恢复数据库」
    3. 选择从电脑A复制过来的 .db 文件
    4. 恢复完成后，重启应用生效

  常见问题解答（FAQ）
═══════════════════════════════════════════════════════════════════════

  Q1：安装后双击打不开？
  ─────────────────────────────────────────────────────────────────
  A：请按以下顺序排查：
     ① 确认系统架构为 arm64（终端执行 uname -m，应显示 aarch64）
     ② AppImage 需勾选「允许作为程序执行」
     ③ deb 包安装后若提示依赖缺失，执行 sudo apt-get install -f
     ④ 仍无法打开，尝试命令行启动查看错误信息

  Q2：系统连上外网后，数据会上传到云端吗？
  ─────────────────────────────────────────────────────────────────
  A：不会。桌面版所有数据仅保存在本地 SQLite 数据库，
     不涉及任何云端同步或数据上传。

  Q3：如何清空演示数据，只保留自己录入的数据？
  ─────────────────────────────────────────────────────────────────
  A：进入「系统管理 → 数据库管理 → 清空演示数据」即可。
     此操作仅清除预设演示数据，不会删除用户自行录入的内容。

  Q4：数据库文件存放在哪里？
  ─────────────────────────────────────────────────────────────────
  A：数据库文件路径为：
       ~/.config/食堂智慧管理系统/canteen.db
     如需手动备份，可直接复制该文件。

  Q5：如何更新到新版本？
  ─────────────────────────────────────────────────────────────────
  A：新版本发布时，请先备份数据库文件，
     然后卸载旧版本并安装新版，最后恢复数据库即可。

  Q6：能否打印报表或导出 Excel？
  ─────────────────────────────────────────────────────────────────
  A：各数据列表页面均支持导出 Excel 功能，
     报表打印可通过浏览器的打印功能实现。
